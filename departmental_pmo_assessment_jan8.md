## Methodology

### Assessment Approach

**Phase 1: Channel Access & Navigation (Browser Automation)**
For each of the 9 channels, execute the following steps:

1. Navigate to channel URL: `https://<workspace>.slack.com/archives/<channel-id>`
2. Verify channel access and member count
3. Check for Canvas and Lists tabs
4. Search for recent activity: Use Slack search with `after:2025-12-01` filter
5. Keyword scan for critical issues

**Phase 2: Data Collection**
For each channel, collect:
- Last message timestamp
- Total messages in period (Dec 1, 2025 - Jan 8, 2026)
- Member count and list of active contributors
- Presence of project tracking tools (Canvas, Lists)
- Messages containing keywords: blocker, urgent, escalation, help, stuck, delay, risk, critical

**Phase 3: Analysis**
- Categorize channels: Active (>20 msgs/week), Moderate (5-20 msgs/week), Low (<5 msgs/week), Dormant (no activity)
- Identify engagement patterns: Structured updates vs ad-hoc discussions
- Flag urgent items requiring immediate attention
- Assess coordination quality based on thread depth, response times, resolution tracking

**Phase 4: Synthesis & Recommendations**
- Cross-channel comparison
- Best practice identification
- Gap analysis and intervention recommendations

### Browser Automation Sequence

```
FOR EACH channel IN [adtrplan, bodplan, boplan, brplan, brplan-counterparty, cex_pmo, cfplan, complan, hrp]:
  1. browser_navigate(channel_url)
  2. screenshot_capture(f"{channel}_overview")
  3. browser_click("Members" tab) → count members
  4. browser_click("Search in channel")
  5. browser_fill_search("after:2025-12-01")
  6. extract_message_count()
  7. browser_click("Canvas" tab if exists)
  8. browser_click("Lists" tab if exists)
  9. browser_fill_search("blocker OR urgent OR escalation OR help OR stuck OR delay OR risk")
  10. extract_critical_messages()
  11. document_findings()
END FOR
```

## Assessment Framework: Channel Health Scoring

### Scoring Criteria (0-100 scale)

**Activity Level (30 points)**
- 25-30: Daily updates, consistent engagement
- 15-24: Weekly updates, regular participation
- 5-14: Sporadic updates, minimal activity
- 0-4: Dormant, no recent activity

**Project Tracking Quality (25 points)**
- 20-25: Canvas/Lists actively used, clear project status
- 10-19: Some tracking tools, inconsistent updates
- 5-9: Ad-hoc tracking, no formal structure
- 0-4: No project tracking visible

**Engagement Quality (25 points)**
- 20-25: Structured updates, clear ownership, timely responses
- 10-19: Mixed quality, some structure, delayed responses
- 5-9: Mostly ad-hoc, unclear ownership, slow responses
- 0-4: Poor engagement, no clear patterns

**Critical Issue Management (20 points)**
- 16-20: Blockers identified early, clear escalation, resolution tracking
- 8-15: Some issue visibility, inconsistent follow-up
- 4-7: Issues mentioned but not tracked
- 0-3: No visible issue management

### Health Categories
- **Excellent (80-100):** Well-functioning PMO coordination
- **Good (60-79):** Adequate coordination, minor improvements needed
- **Needs Improvement (40-59):** Significant gaps in PMO practices
- **Critical (0-39):** Dormant or dysfunctional coordination
